# 🌿 VerdantDiary

**Jurnal hijau untuk kebun sayurmu.**

Status: 🚧 *In Development — Tugas Individu Mobile Programming*

VerdantDiary adalah aplikasi mobile untuk mencatat dan memantau perawatan tanaman sayur-mayur rumahan. Aplikasi ini membantu pengguna mengatur jadwal siram dan pupuk, mendokumentasikan pertumbuhan tanaman melalui jurnal foto, serta memperkirakan waktu panen berdasarkan jenis sayur yang ditanam.

## ✨ Fitur

- 🌱 **Daftar Tanaman** — tambah, edit, hapus data tanaman
- ⏰ **Jadwal & Pengingat** — jadwal siram/pupuk otomatis dengan notifikasi
- 📓 **Jurnal Pertumbuhan** — dokumentasi foto & catatan perkembangan tanaman
- 📊 **Estimasi Panen** — progress bar menuju waktu panen berdasarkan jenis sayur

## 🛠️ Tech Stack

- **Framework:** Flutter
- **Bahasa:** Dart
- **Database:** SQLite
- **Notifikasi:** flutter_local_notifications
- **Gambar:** image_picker
